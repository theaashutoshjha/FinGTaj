All 50 calculation engines execute **exclusively inside client-side browser RAM** with zero server logging, zero database retention, and zero telemarketing lead auctions.

## 🚀 Quick Start & Development

### 1. Clone the repository
```bash
git clone https://github.com/theaashutoshjha/FinGTaj.git
cd FinGTaj
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 4. Build for production
```bash
npm run build
```

### 5. Run test verification suite
```bash
npm test
```
